# 💸 Expense Tracker

A clean, minimal expense tracking web app built with HTML, CSS, and JavaScript.

## Features
- Add expenses with amount, note, category and date
- Summary cards — total spent, this month, total entries
- Donut chart showing spending by category
- Delete individual expenses
- Export all expenses as CSV
- Data persists via localStorage — no backend needed

## Tech Used
HTML · CSS · JavaScript · Chart.js

## How to Run
Just open index.html in your browser. No setup needed.
